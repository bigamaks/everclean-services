# Everclean Home Services — Adversix demo

Responsive Next.js concept website for a fictional residential cleaning company.

## Run locally

Requirements: Node.js 18.18+ (Node.js 20 LTS recommended).

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Quote form

The multi-step quote form collects service, property, schedule, and contact details. On submission it prepares an email in the visitor's default mail application. It does **not** save submissions to a database or send them to a server.

Before using this as a real client website:
1. Replace the fictional business name, contact details, service area, and copy.
2. Replace `hello@everclean-demo.com` with the business's real email.
3. Connect the form to a backend (e.g. Supabase, a server action, or CRM endpoint).
4. Configure owner notifications and customer acknowledgements.
5. Replace sample photography with licensed client-approved images and add authentic reviews only.
6. Review legal, privacy, accessibility, and service-area details with the client.

Everclean Home Services is a fictional concept brand created by Adversix. Do not present it as a real client or imply sample content represents verified customer reviews or results.
